# TwitchChat — Локальный чат Twitch для OBS

Локальный чат Twitch для OBS. Программа работает на твоём компьютере: подключается к чату канала и отображает сообщения в виде браузерного виджета. По принципу работы похожа на KapChat, но использует собственный сервер, интерфейс и оформление.

TwitchChat позволяет самостоятельно настраивать практически каждый элемент отображения чата: от шрифтов и цветов до фильтрации сообщений и подсветки отдельных пользователей.

Логин канала нигде не зашит. Можно подключиться к любому Twitch-каналу, указав его логин или ссылку.

## Что умеет

- Подключается к чату Twitch по IRC и показывает сообщения в реальном времени.
- Поддерживает смайлики Twitch, BetterTTV, 7TV и FrankerFaceZ.
- Отображает бейджи модераторов, VIP, подписчиков и другие значки канала.
- Показывает цветные ники, сообщения и время отправки.
- Поддерживает ответы, рейды, подписки, подарки и объявления.
- Отображает системные сообщения о подключении и ошибках.
- Позволяет настраивать внешний вид чата непосредственно в приложении.
- Содержит предпросмотр оформления, позволяющий увидеть изменения до сохранения.
- Позволяет настраивать шрифты, цвета, размеры, прозрачность, рамки, скругления и анимации.
- Поддерживает фильтрацию сообщений по никам, словам и командам.
- Позволяет подсвечивать сообщения модераторов, VIP, подписчиков, определённых пользователей и сообщения с заданными словами.
- Позволяет отдельно включать и отключать различные наборы смайликов.
- Поддерживает настройку количества отображаемых сообщений, их направления и времени исчезновения.
- Сохраняет настройки оформления между запусками приложения.
- Работает в системном трее: окно можно закрыть, не останавливая сервер. Из трея доступно копирование ссылки виджета и выход из приложения.

Виджет открывается по адресу `http://localhost:3000`. Он имеет прозрачный фон и предназначен для размещения поверх трансляции в OBS.

## Как пользоваться

1. Установи и запусти TwitchChat.
2. Введи логин Twitch-канала или ссылку вида `https://www.twitch.tv/канал`.
3. Нажми «Старт».
4. Скопируй ссылку виджета.
5. В OBS добавь источник «Браузер» и вставь скопированную ссылку.
6. При необходимости открой настройки и настрой оформление чата под свою трансляцию.

Ширину и высоту источника в OBS можно установить самостоятельно.

## Настройки

В приложении доступны пять разделов:

- **Вид** — фон, прозрачность, рамки, скругления, шрифт, размер и цвет текста, направление сообщений, выравнивание и анимация.
- **Сообщения** — оформление подложек, отступы, бейджи, ники, время, ответы, системные сообщения и ограничение длины сообщений.
- **Фильтры** — скрытие сообщений от определённых пользователей, команд и сообщений с заданными словами.
- **Подсветка** — выделение сообщений модераторов, VIP, подписчиков, первых сообщений, определённых пользователей и ключевых слов.
- **Смайлы** — управление Twitch, BetterTTV, 7TV и FrankerFaceZ, а также настройка размера смайликов.

Изменения можно предварительно посмотреть в окне предпросмотра, сохранить или сбросить.

## Разработка

Для запуска проекта из исходного кода необходим Node.js и npm.

Установка зависимостей:

```bash
npm install
```

Запуск приложения:

```bash
npm start
```

Запуск локального сервера отдельно:

```bash
npm run server
```

Сборка для macOS:

```bash
npm run build:mac
```

Сборка для Windows:

```bash
npm run build:win
```

Версия приложения и параметры сборки находятся в `package.json`.
