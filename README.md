# ChatServer

Локальный чат Twitch для OBS. Программа работает на твоём компьютере: забирает чат канала и отдаёт его как виджет. В OBS этот виджет вставляется ссылкой, как KapChat, только сервер свой и оформление своё.

Логин канала нигде не зашит. В окне можно ввести любой канал или ссылку на него.

## Что умеет

- Подключается к чату Twitch по IRC и показывает сообщения в реальном времени.
- Смайлики Twitch, BetterTTV, 7TV и FrankerFaceZ.
- Бейджи: модератор, VIP, подписчик и остальные значки канала.
- Ник цветом пользователя, текст сообщения, время.
- Ответы, рейды, подписки, подарки и объявления.
- Системные строки в виджете: чат подключился или что-то упало. Они не закреплены и уезжают вверх вместе с новыми сообщениями.
- Окно можно закрыть. Программа остаётся в трее. Оттуда же копируется ссылка для OBS и делается выход.

Виджет открывается по адресу `http://localhost:3000`. Фон у него полупрозрачный, чтобы в OBS его можно было положить поверх стрима.

## Как пользоваться

1. Поставь программу.
2. Введи логин канала или ссылку вида `https://www.twitch.tv/канал` и нажми «Старт».
3. Скопируй ссылку кнопкой внутри строки.
4. В OBS добавь источник «Браузер» и вставь эту ссылку.

Ширину и высоту источника в OBS выставляешь сам. Чат прижат к низу виджета.

На macOS приложение не подписано. Если система его блокирует, открой через правый клик → «Открыть».

## Сборки

Пользователю ничего доставлять не надо: рантайм уже внутри установщика.

- macOS: `ChatServer-<version>-arm64.dmg` и установщик `ChatServer-<version>-arm64.pkg`. Пакет ставит приложение в «Программы».
- Windows x64: `ChatServer-<version>-x64-setup.exe`. Это отдельное приложение на .NET. Ставится в профиль пользователя, ярлык появляется в меню Пуск. Отдельно .NET ставить не нужно.

Готовые файлы лежат в `dist/` и в git не коммитятся. Номер в имени берётся из `version` в `package.json`.

Для Windows-установщика на Mac нужен NSIS:

```bash
brew install makensis
```

Собрать обе платформы:

```bash
npm run build:mac
```

```bash
npm run build:win
```

Запуск Mac-версии из исходников для разработки:

```bash
npm install
```

```bash
npm start
```

## Релиз

Релизы собираются локально и файлы кладутся в GitHub Release руками. GitHub Actions нет.

Подними `version` в `package.json`, закоммить, запушь, собери, затем создай релиз с тегом той же версии и прикрепи dmg, pkg и setup.exe.
